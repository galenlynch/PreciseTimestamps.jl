# PreciseTimestamps [![Stable](https://img.shields.io/badge/docs-stable-blue.svg)](https://galenlynch.github.io/PreciseTimestamps.jl/stable/) [![Dev](https://img.shields.io/badge/docs-dev-blue.svg)](https://galenlynch.github.io/PreciseTimestamps.jl/dev/) [![Build Status](https://github.com/galenlynch/PreciseTimestamps.jl/actions/workflows/CI.yml/badge.svg?branch=main)](https://github.com/galenlynch/PreciseTimestamps.jl/actions/workflows/CI.yml?query=branch%3Amain) [![Coverage](https://codecov.io/gh/galenlynch/PreciseTimestamps.jl/branch/main/graph/badge.svg)](https://codecov.io/gh/galenlynch/PreciseTimestamps.jl)

Utilities for representing time with nanosecond precision with an emphasis on
serialization and deserialization to different acquisition and storage formats,
like matlab files, and postgres.

Largely redundant with TimesDates.jl.
